Leeds CMS grabber bookmarklet

A bookmarklet is a bookmark that runs a small script on the page you are looking at. This one opens the "Send to Leeds CMS" pane on any leeds.ac.uk page. Nothing is installed.

Drag this button to your bookmarks bar (show the bar with Ctrl+Shift+B if it is hidden). Do not click it here.

Send to Leeds CMS

Using it

  1. Open the CMS (double-click index.html) in one tab.
  2. Open a leeds.ac.uk page in another tab and click the bookmark.
  3. In the pane choose: whole page, main content, pick a section, or a whole site section (several pages).
  4. Click Copy. Switch to the CMS, go to Import, paste into the box and click Analyse.

If the CMS is running from the local server at http://localhost:8765, Send to CMS delivers directly instead. The Chrome extension in the chrome-extension folder does the same without a server.

If the bookmarklet does nothing

Some pages block scripts from bookmarks. Use the extension instead, or save the page (Ctrl+S, "Webpage, HTML only") and use "From a file" on the Import screen.
